# Реализация дерева решений с бэггингом на C

Проект реализует дерево решений и ансамбль деревьев на языке C. Поддерживаются задачи классификации и регрессии. Для классификации доступны критерии Джини и энтропия, для регрессии используется MSE. Ансамбль использует bootstrap-выборки, случайную подвыборку признаков на каждом узле и случайный выбор части деревьев при итоговом голосовании/усреднении.

Программа умеет:

- обучать ансамбль деревьев на CSV-файле;
- предсказывать команду робота по значениям признаков;
- решать регрессионную задачу и предсказывать числовое значение;
- запускать встроенную демонстрацию без внешних данных;
- проверять корректность основных функций через unit-тесты;
- сохранять кривую обучения при помощи Python-скрипта.

## Суть задачи

По сенсорным данным робота нужно выбрать одну из команд движения. В демонстрационном датасете используются четыре признака:

| Признак | Значение |
| --- | --- |
| `obstacle_dist` | расстояние до препятствия |
| `speed` | текущая скорость |
| `turn_angle` | угол поворота: отрицательный — влево, положительный — вправо |
| `battery` | уровень заряда батареи |

Классы, которые предсказывает модель:

- `forward` — двигаться вперед;
- `turn_left` — повернуть налево;
- `turn_right` — повернуть направо;
- `stop` — остановиться.

## Что реализовано

### Дерево решений для классификации

Дерево строится рекурсивно. На каждом узле алгоритм ищет лучшее разбиение данных по одному из признаков и порогу. Качество разбиения может оцениваться через индекс Джини:

```text
Gini = 1 - sum(p_i^2)
```

или через энтропию:

```text
Entropy = -sum(p_i * log2(p_i))
```

где `p_i` — доля объектов класса `i` в узле. Критерий выбирается при создании дерева или через CLI-команду `train`.

### Дерево решений для регрессии

В регрессионном режиме последний столбец CSV считается числовой целевой переменной. Разбиения выбираются по уменьшению среднеквадратичной ошибки:

```text
MSE = mean((y_i - mean(y))^2)
```

В листе хранится среднее значение целевой переменной для объектов, попавших в этот лист.

Узел становится листом, если:

- достигнута максимальная глубина дерева;
- в узле меньше объектов, чем `min_samples_split`;
- все объекты в узле относятся к одному классу;
- невозможно найти полезное разбиение.

### Случайная подвыборка признаков

При поиске разбиения дерево рассматривает не все признаки, а случайное подмножество. По умолчанию для bagging используется:

```text
sqrt(number_of_features)
```

Это делает деревья в ансамбле менее похожими друг на друга и повышает устойчивость предсказания.

### Bagging и случайный выбор деревьев

BaggingClassifier обучает несколько деревьев. Для каждого дерева создается bootstrap-выборка: объекты выбираются случайно с возвращением.

Дополнительно при предсказании можно использовать не все деревья, а случайное подмножество `vote_trees`. Для классификации итог выбирается большинством голосов выбранных деревьев, для регрессии — усреднением их ответов.

## Требования

Для сборки нужны:

- CMake 3.16 или новее;
- компилятор C с поддержкой стандарта C99;
- стандартная математическая библиотека `m`.

На macOS обычно достаточно установленного Xcode Command Line Tools и CMake.

## Сборка

Из корня проекта выполните:

```bash
cmake -S . -B build
cmake --build build
```

После сборки исполняемый файл будет находиться здесь:

```bash
./build/robot_dt
```

## Запуск

### 1. Встроенная демонстрация

```bash
./build/robot_dt demo
```

Демонстрация создает небольшой датасет прямо в коде, обучает одиночное дерево и ансамбль из 10 деревьев, затем выводит несколько предсказаний.

### 2. Обучение классификации на CSV

```bash
./build/robot_dt train data/robot.csv 10 5 entropy 7
```

Аргументы:

| Аргумент | Описание |
| --- | --- |
| `data/robot.csv` | путь к датасету |
| `10` | количество деревьев в ансамбле |
| `5` | максимальная глубина каждого дерева |
| `entropy` | критерий классификации: `gini` или `entropy` |
| `7` | сколько случайно выбранных деревьев участвует в голосовании |

Пример результата:

```text
Загрузка датасета: data/robot.csv
Образцов: 20  Признаков: 4  Классов: 4
Обучение (10 деревьев, глубина 5, критерий entropy, голосуют 7 деревьев)...
Точность на обучающей выборке: 100.00%
```

### 3. Предсказание команды

```bash
./build/robot_dt predict data/robot.csv 4.5 0.8 3.0 0.85
```

Значения признаков передаются в том же порядке, что и столбцы в CSV-файле, кроме последнего столбца с меткой класса.

Для `data/robot.csv` порядок такой:

```text
obstacle_dist speed turn_angle battery
```

Пример результата:

```text
Предсказание: forward
```

Важно: команда `predict` каждый раз заново обучает ансамбль на переданном CSV-файле, а затем делает одно предсказание. Сохранение обученной модели в файл в текущей версии не реализовано.

### 4. Регрессия

Для регрессии используется файл `data/robot_runtime.csv`. Последний столбец содержит числовую целевую переменную `runtime_minutes`.

```bash
./build/robot_dt train-reg data/robot_runtime.csv 20 6 12
./build/robot_dt predict-reg data/robot_runtime.csv 4.5 0.8 3.0 0.85
```

Пример результата:

```text
RMSE на обучающей выборке: 0.9102
Предсказанное значение: 44.6000
```

## Формат CSV

CSV-файл должен содержать заголовок. Для классификации последний столбец считается меткой класса, все предыдущие столбцы — числовыми признаками.

Пример:

```csv
obstacle_dist,speed,turn_angle,battery,command
5.0,1.0,0.0,0.90,forward
3.0,0.5,-30.0,0.60,turn_left
3.0,0.5,30.0,0.60,turn_right
0.3,0.0,0.0,0.20,stop
```

Ограничения, заданные в `src/decision_tree.h`:

| Ограничение | Значение |
| --- | --- |
| Максимальное число классов | `16` |
| Максимальное число признаков | `64` |
| Максимальная длина названия класса | `64` символа |

Для регрессии формат такой же, но последний столбец должен быть числом:

```csv
obstacle_dist,speed,turn_angle,battery,runtime_minutes
5.0,1.0,0.0,0.90,48.0
0.3,0.0,0.0,0.20,9.0
```

## Кривая обучения

Кривая обучения строится Python-скриптом из папки `scripts/`. Скрипт запускает C-программу с разным числом деревьев и сохраняет результаты в CSV и SVG.

```bash
python3 scripts/learning_curve.py classification
python3 scripts/learning_curve.py regression
```

Результаты сохраняются в папку `learning_curve/`:

```text
classification_learning_curve.csv
classification_learning_curve.svg
regression_learning_curve.csv
regression_learning_curve.svg
```

## Тестирование

Сначала соберите проект, затем выполните:

```bash
ctest --test-dir build --output-on-failure -V
```

В тестах проверяются:

- выделение и освобождение памяти для датасета;
- загрузка CSV с заголовком и без заголовка;
- обработка некорректного пути к файлу;
- расчет индекса Джини;
- расчет энтропии;
- обучение и предсказание одиночного дерева;
- обучение и предсказание регрессионного дерева;
- работа bagging-классификатора;
- случайный выбор подмножества деревьев при голосовании;
- регрессионный bagging и расчет RMSE;
- многоклассовая классификация;
- интеграционный сценарий с CSV для робота;
- граничные случаи: один объект, одинаковые признаки с разными метками.

На момент проверки проект собирается успешно, тесты проходят:

```text
103 passed, 0 failed
100% tests passed, 0 tests failed out of 1
```
